# /pm — 需求提交入口

**本 workflow 是所有正式开发请求的唯一入口。**

执行步骤：读取并严格遵循 `D:/toolBox/PM/pm_workflow.md` 中的完整指令。

## Quick Reference

1. 创建 session 目录 → `.in-process/active/{id}/`
2. 记录原始请求
3. 召回上下文（Error_Book → KI → Skills Index → Project Rules）
4. 分析需求，必要时向用户提问
5. 输出 `requirement_package.md`
6. Gate① 自检 → 通过后交接 CTO Planning
