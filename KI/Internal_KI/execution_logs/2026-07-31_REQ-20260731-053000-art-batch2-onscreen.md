# REQ-20260731-053000 — 对局切图第二批入库与上屏（通宵自主作业）

## 需求原文与授权边界

用户睡前一句话下达：「审计每个图片 → 重新命名 → 变成 sprite frame → 放到游戏对局里该放的位置 →
做完要 codex 先交叉验证」，并明示「我现在要去睡觉了，你尽力做，我起来审计」。

**这是一个"授权自主、事后审计"型任务**：范围由 agent 自行判定，无中途澄清机会。
本类任务的特征是——**能问的问题必须在动手前自问，答不了的必须落成"候拍板"清单**，而不是替用户拍板。

## 关键判断（事后看仍然正确的）

| 判断 | 内容 | 依据 |
|---|---|---|
| 分层执行 | 把 30 张图分成 Tier A（纯换图，零代码）与 Tier B（要动结构/代码），A 先落地建立信心再做 B | 失败半径可控；A 出问题不牵连代码 |
| 不替用户拍板 | 5 张图（座位状态字 ×2、比分面板 ×3）判定为"结构重建/无数据源"，**入库但不挂**，写进候拍板 | 比分面板涉及局数积分/胜利积分/倍数，客户端根本没有数据源——硬做等于编造协议 |
| 缺件如实回问 | 加倍标记、头像框、金币图标三项美术缺件，写清单回问而非用占位凑 | 占位凑数会让用户误以为已完成 |
| 先勘查后动手 | 开工先派 Explore agent 全仓勘查 9 类挂点 + 命名契约 + 动静态分界 | 该报告直接决定了 Tier A/B 分层，也提前标出"节点名改不得"的红线 |

## 执行序（实际，7 阶段串行）

1. **勘查与管线定案** — Explore 勘查；探针实证 MCP 导入仍落 texture；踩 [[ERR-083__mcp-write-param-triggers-modal-deadlock|ERR-083]] 重启编辑器；定案 [[PAT-040__meta-inheriting-asset-import-bypass|PAT-040]] 管线
2. **资产量产** — 30 张 copy+覆写+reimport，四断言全量验收 30/30
3. **Tier A 换装** — 16 处 spriteFrame 赋值 + 尺寸修正，磁盘断言 + git 基线对照
4. **Tier B 结构改造** — Label→Sprite ×5、新建节点 ×20、删 lbl ×3、贡钮两态
5. **代码接线** — 3 处改动 + 编辑器重编译实证
6. **守门与视觉** — typecheck×2 / layoutband 49 项 / panelnodes / 镜像链；截图验证**当场揪出 [[ERR-084__placeholder-decorations-survive-real-asset-swap|ERR-084]] 两枚缺陷**
7. **Codex 交叉验证** — 1 轮，三问分诊后定向返修

## 结果

- 30/30 入库（零人工介入，破解既往"编辑器手工步"死结）
- 25 张上屏，prefab 433→450 节点，代码 3 处
- Codex 判：A/B/C/D/G 五项零反例；E（代码）+ F（契约账实）FAIL，均已修
- 终态 QA PASS，候用户亲验 + 4 项拍板

## 本轮回炉复盘（用户明确要求"以后别犯"）

| # | 回炉 | 归档 | 一句话 |
|---|---|---|---|
| 1 | `import overwrite=true` 弹模态框锁死 MCP，被迫重启编辑器 | [[ERR-083__mcp-write-param-triggers-modal-deadlock\|ERR-083]] | 编辑器内嵌 MCP，会弹框的参数是自杀开关 |
| 2 | 换图后旧 tint 压暗新图 + 占位框盖住头像 | [[ERR-084__placeholder-decorations-survive-real-asset-swap\|ERR-084]] | 换图是让整套占位手段退场，不是换一个字段 |
| 3 | major REQ 缺 plan/DAG/证据即进 QA | [[ERR-085__state-machine-stamped-gates-without-evidence-artifacts\|ERR-085]] | Gate 通过的证明是文件，不是我说通过了 |
| 4 | **末游徽章 idx=3 漏判（ERR-075 复犯）** | [[ERR-075__incremental-path-fixed-snapshot-path-forgotten\|ERR-075]] 复犯 #1 | 增量/快照一致性要查"取值域"，不只是"字段有无" |
| 5 | set_property 传字符串对象值静默写 100×100；reorder 甩节点到根；move 的 siblingIndex 不生效；跨 edit 会话 uuid 换代 | [[ERR-069__cocos-mcp-tool-quirks-collection\|ERR-069]] 第二批实证 | `changeVerified:false` 是唯一线索，别只看 success |
| 6 | 手打 uuid typo，工具照报 verified | [[ERR-081__mcp-spriteframe-dburl-persists-fake-uuid\|ERR-081]] 实证+1 | uuid 只从落盘的 uuid_map 程序化取 |
| 7 | 文档账实误差（新增17 vs 新增20删3；挂屏 26 vs 25） | 本条 | 追加修订时混用了"净变化/新增数/决策项数"三种口径 |

**最贵的一条不是技术缺陷，是 #3**：它让前面所有正确的工作在审计面前失去背书。
**最需要警惕的是 #4**：三天前刚记的教训，在一个自认为已吃透的场景里原样复犯——
说明"记住规则"不等于"用对规则"，规则的**适用边界**同样要写进条目。
